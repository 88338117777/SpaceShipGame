# 失重第九小时 · 第一人称舱外冒险

v0.2 是完整第一人称可玩灰盒。玩家穿着航服，实时沿空间站外壁飞行，躲避高速陨石、推动低速陨石借力，用航服机械臂抓握扶手并处理持续漏气，最后抓住装有氧气花的培养舱并连接回收系缆。

本版按重新确认的需求定位为动作冒险，不再追求原题的“物理益智”分类。仍保留 270 秒正常通关目标、1 血可通关、开局 5 秒安全、就近复活、死亡辅助及 A 轨接力协议。没有轨迹预测、回合执行或第三人称规划界面。

## 运行与试玩

项目已经提供完整构建产物，无需先安装 npm 依赖。在项目根目录运行：

```bash
npm run dev
```

打开 http://127.0.0.1:8080/game/ 。点击“打开气闸，开始行动”后进入鼠标锁定；按 Esc 打开菜单。如果浏览器不支持鼠标锁定，可以按住左键拖动观察，用 E 交互。

键鼠操作：

- 鼠标：自由观察；镜头保持统一上下方向，没有侧滚。
- W / A / S / D：相对视角推进。松键仍保留惯性。
- Space / C：垂直升降；左 Ctrl 也支持下降。
- Shift：强力推进。持续约 3.7 秒会过热，冷却后恢复；小幅推进始终可用。
- X：主动反推制动，过热时仍可用。
- E：对准目标伸出机械臂。可抓扶手、取补给、推低速陨石、扣住培养舱把手。固定后移开补给目标，再按 E 松开。
- R：抓稳扶手、拥有胶带且存在破口时，按住 3 秒修补。松键取消，不消耗胶带。
- M：开关航服声音。
- Esc：暂停并打开菜单；点击“继续行动”恢复。暂停时运动和氧气冻结，任务总计时继续。

高低速陨石有不同用途。高速掠过的陨石会撞偏航服并增加持续漏气；低速岩块可近距离推出，航服获得反向动量。碰撞不直接扣生命，氧气耗尽才扣 1 血；归零后由官方接口复活。扶手所在的带护板维护架提供安全修补位置。

主路维护架有保底补给，远离主路的漂浮补给箱提供更多氧气和胶带。培养舱缓慢漂移；接近时先制动，速度小于约 2.2m/s 后抓取，随后播放约 6.5 秒的系缆回收演出。氧气花留在空间站，跨关奖励为空。

## 接力模拟器

打开 http://127.0.0.1:8080/participant-delivery-kit-v3.3.2/mock-runner.html ，选择 `game/global-items.json`，入口填写 `http://127.0.0.1:8080/game/`，再选择入场存档并启动。

正式接力验收必须通过 HTTP 与隔离 iframe，不以双击文件替代。运行代码已打成普通脚本，兼容没有 allow-same-origin 的 iframe；无需外部 CDN、网络素材或线程。单独打开游戏会显示本关结局，成功跨关交接由大厅/模拟器接收。官方协议库未修改。

## 开发与验证

- `src/main.mjs`：实时键鼠输入、HUD、状态管理与协议。
- `src/physics.mjs`：120Hz 三维惯性、碰撞、抓握、热量、漏气、修补和救援。
- `src/world.mjs`：舱外结构、维护点、补给、低速陨石与高速陨石分布。
- `src/view.mjs`：第一人称相机、程序几何场景、航服机械臂、修补动画与回收演出。
- `src/audio.mjs`：程序生成的航服推进、漏气与操作声音。
- `vendor/`：本地 Three.js 0.165.0，许可证随运行包提供。
- `game/`：完整可运行产物。

修改源码需 Node.js 22+，先运行 `npm install` 安装开发依赖：

```bash
npm run build
npm test
npm run check
npm run pack
```

已有开发依赖可通过 `ESBUILD_PATH`、`JSDOM_PATH`、`PLAYWRIGHT_PATH` 指向对应 npm 包目录。运行游戏本身不需要这些包。

真实浏览器验收先安装 Playwright Chromium（`npx playwright install chromium`），然后执行 `npm run test:browser`；也可用 `CHROME_PATH` 指向现有 Chrome。脚本在官方 iframe 中发送正常键鼠输入，不修改游戏状态，保存截图与 `output/browser-result.json`。该脚本要求鼠标锁定成功；不支持鼠标锁定时需人工验证拖动观察的替代方式。

本轮已通过 23 项测试：14 项物理/生存测试、7 项实际键鼠事件及官方协议流程测试、2 项 Three.js 场景对象测试。场景对象测试不执行 GPU 渲染。完整键鼠流程模拟约 143.05 秒，保持 1 血并到达结局；这不是实际浏览器或人工通关时间。

当前执行环境禁止本地端口监听，因此浏览器验收未启动，失败原因保存在 `output/browser-result.json`。WebGL 画面、实际性能、鼠标手感、人工 270 秒验收及正式大厅交接仍待验证，详见 `完整流程自测记录.md`。

## 云端部署

服务器已配置 SSH 密钥后，在项目根目录执行：

```bash
npm run deploy
```

脚本依次执行构建、官方目录检查，再通过 rsync 将 `game/` 内的运行文件同步至 `root@game.notical.cn:/www/wwwroot/game.notical.cn/`。访问地址为 https://game.notical.cn/ 。本机和服务器需要安装 rsync；首次构建前需安装项目开发依赖。

使用已有 SSH 密钥与配置，默认用户 `root`、端口 `22`。需要其他账号或端口时可覆盖：

```bash
DEPLOY_USER=deploy DEPLOY_PORT=22 npm run deploy
```

先预览上传变化（仍会构建、检查并连接服务器，但不写入远端）：

```bash
npm run deploy -- --dry-run
```

仅上传游戏运行目录，排除隐藏文件；不使用 `--delete`，保留远端 `.user.ini`、`.well-known` 等站点文件。构建、检查或同步失败会返回非零退出码。
